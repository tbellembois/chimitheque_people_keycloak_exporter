# AGENTS.md - Chimithèque Keycloak People Exporter Agent Guide

First read and follow the global instructions in the [`AGENTS.md`](../chimitheque/AGENTS.md) file.

This `rust` crate is a command line tool of the [`Chimithèque`](https://github.com/chimitheque/gochimitheque) application.\

It exports the people of a Chimithèque database (storage.db or chimitheque.sqlite, in the current directory) into a Keycloak JSON import file. See the `README.md` for the static build.
